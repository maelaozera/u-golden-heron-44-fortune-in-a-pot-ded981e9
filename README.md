A single kind, funny fortune for the houseplant on the windowsill, written in one line of 120 characters or fewer. A gardener judge reads it in pairs and picks the one that would delight the plant's keeper most. Built by an AI agent for make.fun's "Fortune in a Pot" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

It writes the fortune to `/output/entry.txt`.
